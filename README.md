## Тестирование
Класс main покрыт юнит-тестами с использованием фреймворка `pytest`. Тесты проверяют корректность работы всех методов класса `BooksCollector` в различных сценариях.
Тесты используют фикстуру collector, которая создаёт новый экземпляр BooksCollector перед каждым тестом. Для методов, требующих предзаполненных данных, используется фикстура collector_with_books. Фикстуры находится в файле  conftest.py. Многие тесты параметризованы, чтобы покрыть граничные значения.
Запуск тестов 
pytest -v test_books_collector.py
Отчет о покрытии можно проверить с помощью
pytest --cov=main --cov-branch --cov-report=html 
После выполнения отчёт появится в папке htmlcov/.
или --cov=main отобразится в консоли покрытие 

Coverage for main.py: 100%
